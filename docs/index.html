KinRT

Kinematics-guided routing for generalizable robot manipulation.

Future action structure supervises a four-expert router during training. Deployment selects one expert from the current visual, language, and proprioceptive observation only.

Method

Three stages, one routing decision

KinRT adds explicit kinematic supervision without changing the information available to the deployed policy.

01

Build labels

Encode 50-step action chunks, standardize them, project to PCA-64, and cluster into four motion archetypes.

02

Train the router

Mean-pool valid observation-prefix tokens and optimize a dense router with frame-aligned cluster labels.

03

Route at inference

Select one residual expert for the action chunk using only the current observation and instruction.
